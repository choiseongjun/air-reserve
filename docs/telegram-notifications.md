# 문의 텔레그램 알림

서버 전용 환경변수 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 Vercel Production에 설정하고 재배포한다. 로컬 검증 시에는 gitignored `.env.local`에 설정한다. 봇과의 개인 대화에서 먼저 시작 버튼을 눌러야 한다.

예약 폼과 채팅 문의 모두 DB 저장 성공 후 알림을 전송한다. 동일 요청 재시도는 새 알림을 만들지 않는다. 지역·서비스·희망일·사진 수·접수번호와 관리자 링크를 보내며 이름, 연락처, 상세 주소, 사진 원본은 전송하지 않는다.

전송 제한 시간은 회당 5초이며 네트워크 오류 또는 서버 오류에 한 번 재시도한다. 전송 장애는 접수 성공에 영향을 주지 않는다. 영구 재전송 큐는 없으며 실패 시 서버 로그에 접수번호를 남기므로 관리자 접수 목록이 최종 기록이다. 네트워크 응답 유실 시 재시도 알림이 중복될 수 있다.
